# Master (PC) em C++ -- tentativa historica (nao finalizada)

alternativa ao master_py/. Setup de toolchain (MSYS2 + libusb + cmake)
travou em instabilidade dos mirrors do MSYS2 e o codigo nunca chegou a
ser compilado ou testado contra hardware real.

O master ativo do projeto e o master_py/ (Python + python-can/gs_usb),
validado em bancada com o hardware real. Esta pasta fica apenas como
referencia / possivel retomada futura.
